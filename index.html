완료된 업무

업무 추가

반복 업무는 시작일 이후 매주·평일(월~금) 또는 매월 자동 표시되고, 완료 여부는 날짜별로 따로 저장됩니다.
하위 업무는 각자 날짜를 지정할 수 있고, 해당 날짜의 주간/캘린더에도 따로 표시됩니다.

LIVE 업무 생성

기본 생성 항목
예고페이지&배너 디자인 요청 (D-23) / 라이브등록 (D-21) / 라이브 심의 (D-21) / 기본 배너 및 예고페이지 세팅 (D-14) / 미디어벨 빅배너 자료 회신 (D-14) / 미디어벨 방송 스킴 전달 (D-10) / CS 행사 공유 (D-7) / 브랜드 검색광고: 라이브소재 추가 (D-5) / 이벤트 등록 (D-3) / 톡톡메시지 발송 (D-3) / 라이브 가격 세팅 확인 (D-1) / 적립금세팅·쿠폰·소비기한체크 (당일) / 이벤트 사은품발송 (D+14)
라이브 진행일을 기준으로 각 하위 업무의 날짜가 D-23부터 D+14까지 자동 계산됩니다. 생성 후에는 각 업무의 날짜와 우선순위를 자유롭게 수정할 수 있습니다.

기본 생성 항목
